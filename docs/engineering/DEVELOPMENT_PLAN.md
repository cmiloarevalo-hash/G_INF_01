# Development Plan

**Estado:** estrategia TARGET para una aplicación todavía en preimplementación. No establece calendario, fases, gates ni tareas.

## 1. Development Objective

Desarrollar la herramienta web ligera de análisis documental y Estudio de Títulos como primer tipo, preservando el alcance completo del producto aprobado. La calidad del análisis LLM, instrucciones del informe, contrato JSON y generación profesional concentran el valor del producto.

## 2. Development Priorities

La interfaz es central y debe definirse antes de desarrollar completamente el motor. La mayor complejidad intelectual se concentra en prompt por tipo, LLM, JSON Schema, interpretación documental y generación del informe. El resto se resuelve con software web sencillo. El primer tipo de informe es `TITLE_STUDY`; Google Drive pertenece al producto completo y no se reclasifica como función futura. Su orden específico de implementación no está definido.

## 3. Suggested Development Sequence

La única relación de precedencia de producto expresamente definida es definir la interfaz antes de completar el motor. El Estudio de Títulos es el primer tipo de informe. El orden restante de implementación no está determinado por las fuentes y no altera el alcance aprobado.
